# Support

## Bugs

Use the [bug report form](https://github.com/euforic/AgentDock/issues/new?template=bug_report.yml)
for reproducible AgentDock problems. Include the AgentDock version, macOS
version, provider app version, expected behavior, actual behavior, and sanitized
reproduction steps.

## Feature Requests

Use the [feature request form](https://github.com/euforic/AgentDock/issues/new?template=feature_request.yml)
to describe the problem, intended users, and desired outcome. Proposals that
change provider launch contracts, persistence, destructive behavior, or privacy
boundaries need especially clear motivation.

## Security

Report vulnerabilities privately as described in
[`SECURITY.md`](SECURITY.md). Do not publish exploit details or sensitive
evidence in an issue.

## Provider Account Help

AgentDock does not control provider authentication, billing, account access,
service availability, or cloud conversation synchronization. Contact the
relevant provider for those issues.

## Public Data Hygiene

Before posting diagnostics:

- replace usernames and home-directory paths;
- remove account names, emails, tokens, and identifiers;
- omit transcript and tool-output content unless a synthetic example is enough;
- attach no profile database, browser state, Keychain export, or crash report
  without reviewing it for private data.
